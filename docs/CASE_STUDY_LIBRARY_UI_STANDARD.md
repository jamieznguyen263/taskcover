# Case Study Library UI Standard

Task 13C replaces the old stacked registry with a premium verified case-study library.

## Standard

- Lead with a featured case-study highlight.
- Use a top filter bar with industry, market, service, result count, and clear filters.
- Render cards in a two-column desktop grid and a stacked mobile layout.
- Show client name, industry/market context, verified metric value, metric context, related service names, and a clear case-study CTA.
- Resolve service names through the service registry. Do not display raw slugs like `technical-seo`.
- Use centralized local client logo assets for hub and results-card logo
  visuals; keep full case-study gallery visuals on detail pages.
- Preserve logo and gallery aspect ratios.

## Proof Modules

The hub now includes:

- Verified Outcomes by Growth Lever: metric label, value, client, related growth lever, context, and full case link.
- Service-to-Proof Map: localized service name, description, related case examples, usage count, service CTA, and library CTA.

## Not Changed

No routes, slugs, sitemap rules, canonicals, hreflang, or SEO ownership maps changed for Task 13C.
